      BF Type Generator

      랜덤 Problem Grid 위에 위계 규칙을 지키면서 타이포를 얹어요. 시드 번호로 같은 시안을 다시 불러올 수 있어요. 저장 버튼: PNG(기본) · 투명(배경·패턴 없이 글자·로고·손그림만) · 그리드(그리드 선 포함) · SVG 아웃라인(Figma용: 글자가 벡터라 모양은 가이드 장평 그대로, 다시 타이핑만 안 됨) · SVG 텍스트(Figma용: 장평 대신 가장 가까운 Neue Plak 폭 패밀리로 바꿔 타이핑 가능, 모양은 조금 달라짐). 둘 다 레이어 분리 + 그리드 레이어 포함.

      레이아웃 — 불규칙: drop(한 칸씩 내려가기) · ref(가운데만 내려감) · span(한 단어가 여러 칸) · split(장평 190 vs 30) / 간단: 한 줄 또는 두 줄 왼쪽 정렬, 정보는 바로 아래 표로 / 반복: 같은 문장 반복 · 단어 반복 · 장평 램프 · 지그재그.
      패턴 — 클린/그리티 반복 타이포는 가이드 p56–57 방식(배경과 같은 계열의 톤온톤). 손그림은 가이드 p78 에셋 12종 중 원·밑줄·낙서를 헤드라인 조각 하나에만 써요(가이드: "매우 아껴서"). '빈 칸만'은 글자·로고가 있는 가로 칸을 피해서 패턴을 깔아요(가이드: 텍스처 바로 위에 타이포 금지).
